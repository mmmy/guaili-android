# 小组件信号排版

2026-09-29 实现。

- 信号模式顶部合并为一行：标题与记录数、获取时间、可点击状态、编辑和刷新。320dp 保留完整标题和秒级时间，较窄尺寸简写标题、时间与状态。完整收线时间、校时偏差与具体缺失、过滤、过期信息在“小组件状态”中展开，保留异常入口。
- 普通信号在 250/320dp 使用两行：品种、信号名称、级别数；周期区间、均线方向、变化状态。320dp 的第二行按左/中/右三列分布。
- 320dp 的周期分歧使用三行：标题与总级别数；短端/长端各自方向、范围和级别数；最大周期均线背景与变化状态。
- 180dp 的普通卡片将标题与变化状态换到独立行；较窄的分歧逐段显示短端和长端，避免区间或数量被截断。卡片之间保留独立间隔，品种与标题对齐。
- “原”和“变化”仍标记已退出区间；记录点击仍进入对应 K 线。“未定”表示均线未满足连续方向条件，不等于价格横盘。状态详情提供简写说明、完整校时信息及刷新入口。
- 状态详情计时仅在页面前台运行；不更改信号规则、后台刷新频率或已保存品种选择。

验证：150 项单元测试通过；桌面显示/状态详情/滚动、卡片尺寸及单行栏尺寸测试通过（3 项）。尺寸测试使用真实 RemoteViews 在 180/250/320dp 渲染共 9 种卡片组合及 18 种状态栏组合，检查每个文本字段无省略；单行栏高度不超过32dp，覆盖正常、缺失、待校时、异常、刷新中与失败。Debug APK 与测试 APK 构建成功，Lint 为 0 错误、40 警告。

安装前已备份模拟器的数据，采用覆盖安装。桌面测试临时配置与快照在 finally 中恢复。`build/widget-signals-top.png`、`build/widget-signals-bottom.png` 及 `build/signal-card-*.png` 是测试数据的排版截图。
