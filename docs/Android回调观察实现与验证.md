## 页面与操作

每个品种多头在上、空头在下。目标级别是视觉重点：候选采用 headlineLarge / 32sp / Bold，多头绿色、空头红色直接作用于级别；等待采用 headlineMedium / 28sp / Medium 和较弱方向色。品种、乖离与说明为 12sp 辅助字号，方向与采样时间为 11sp；中性背景不代替方向颜色。目标行最小高度 72dp、圆角 12dp，开关及常用操作保留至少 48dp 触摸区域。

“只显示回调候选”只留下高亮方向，品种没有候选则隐藏。“声音提醒”独立保存，默认关闭。参数包括连续级数 N、强弱阈值 T、强势背景级数 K，以及高级参数最小目标级别、反向容差 R；范围校验失败不保存。设置与原表格／V2 的筛选互不覆盖，旧偏好自动取得回调默认值。

点击目标打开原生依据底部面板；背景、目标、规则与均线参数均固定在打开时的同一份快照。关闭按钮、面板外点击或系统返回取消选择；刷新不能恢复已取消选择。K 线使用真实 symbol 和原始 interval，返回保留列表位置及显示模式。0.4.1 已按新原型将工具栏统一为一行，窄屏和大字体也保留「级数、候选、声音、刷新」，详情见 [单行工具栏与验证](Android回调观察单行工具栏与验证.md)。宽屏保留原有导航侧栏，观察内容限制在 760dp。下方截图及测试记录对应原始 0.4.0 交付。

## 判定与桌面端一致

默认 N=5、T=10、K=2、最小目标 1 分钟、R=3。参数阈值单位是服务器的整数 `value`；方向依据原始 `guaili` 正负。

- 完整 `/api/signals` 的 `perIntervalQuality` 与 `missingIntervals` 按实际时长从大到小排列。重复周期别名、过滤、缺失、过期或无效证据阻断连续性，不能删掉后拼接。
- 每个最大同向段从大级别起点观察第 N 级，不移动窗口去追最小级别。前 N−1 级必须同向，每个多空方向选择最大的合格段。
- 背景全部 `|value| < T` 为弱势，至少 K 个背景级别 `|value| ≥ T` 为强势，其余为普通；目标不参加背景强度计数。
- 弱势／强势的目标原始 `guaili == 0` 高亮。强势目标反向、整数 value 非零且 `|guaili| × 10 ≤ R` 也高亮。普通、等待、截断零、反向超限不高亮，与桌面端的状态优先级一致。
- 原始 guaili 非零但整数 value 为 0，仅表示接近均线；不能作为真实触及均线。这里的真实零来自后端动态 K 线触及均线的计算语义，不代表当前收盘价必然等于均线。

例如背景整数值 `[8,6,5,3]`、目标真实零是弱势回调候选；背景 `[18,14,6,3]`、目标 guaili `−0.2` 是强势多头小幅反向候选。十个连续同向级别仍观察固定的第 5 级。

## 数据、声音与运行效率

复用现有 `ServerSignalsViewModel`、完整快照缓存和刷新协调器，应用与小组件共用快照，不新增行情轮询。切到回调页暂停主矩阵和价格警报页的独立刷新，离开行情页、打开 K 线或退后台取消前台轮询；请求有界且可取消。

服务端 `qualityConfig` 的行情／结果有效期和服务器时间配合 Android 单调时钟判定；缺元信息、子集快照、异常时基和非 live 状态不参与候选计算。新快照／规则变化才重建排序，已有每秒过期检查只在最早有效期边界重建回调投影。LazyColumn 按品种复用，刷新不跳动列表。

提醒身份为品种 + 多空方向 + 实际周期时长；一次更新出现多个新候选只发一个短通知音。同一候选持续存在不重响；有效数据证明消失后再出现可重响。未知、缺失、断网和过期不证明消失。启动、重新进入页面、开启声音、改变判定规则或服务器时静默建立基线；候选显示筛选不改变声音判定。ToneGenerator 使用系统通知音量，离开／停止时释放资源。当前功能是前台观察页提醒，未增加后台监控服务。
