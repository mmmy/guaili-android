# Android 回调价格警报同步与延期

日期：2026-10-14。版本：0.5.0（versionCode 7）。本次按已审核的移动端原型实现，沿用 Kotlin、Compose、Material 3 与既有行情服务；后端代码和部署未改变。

## 使用

- 「行情 → 回调观察」右侧聚合价格警报的交易意图、绑定周期、精确价格与状态；原乖离及强弱仍在依据详情查看。回调目标保持候选 32sp、等待 28sp，多绿空红；推荐小级别保持 16sp。
- 做多、平多归多头行，做空、平空归空头行，旧/未知意图保留未分类入口。每方向显示一条稳定主警报，`+N` 打开其他警报，可设为主；选择按服务地址、品种和方向保存。
- 单击警报打开该品种、绑定周期的 K 线并定位该 ID；原回调级别与推荐小级别分别保留自己的入口。关闭或系统返回取消面板，刷新不恢复已关闭的面板，返回 K 线保持列表位置。
- K 线警报编辑器增加四种交易意图，与穿过、上穿、下穿独立；不会按名字、线色、BUY/SELL 或穿越方向猜测旧记录的意图，也不改写用户消息模板。
- 同品种、规范化周期和已分类意图最多一条启用警报。重复时明确选择编辑已有、原子替换或取消；替换提交旧警报 ID 和版本，由后端事务暂停旧记录并保留历史。

## 延期

启用、未到警报有效期、不向外延伸且范围结束的有限线段，主行和展开面板均提供「延期」。手机点击后打开预览，显示原/新起止时间，再确认执行。

全局「延期 K 线数」默认 20，支持 1–1000，旧配置缺字段自动采用 20。参数取消不保存，非法输入不能保存；与回调规则独立，单独修改不重算候选或重置声音基线。主警报选择与默认延期根数属于手机偏好，警报记录由手机和桌面共享的服务保存。

```text
新终点 = 警报自身品种和绑定周期的最新未收盘 K 线开盘时间 + K × 周期时长
新起点 = 原起点 + 新终点 − 原终点
```

保留原线段时长、端点价格、延伸方式、意图、穿越条件、频率、有效期、通知设置、ID 和历史。新起点在未来时明确显示「延期后等待起点」，保存后按实际时间和服务状态显示「等起点」。确认时重新读取最新 K 线；不会用设备当前时间、推荐小级别或回调目标周期替代绑定周期。

成功后提供 10 秒撤销。撤销要求记录仍启用、未到有效期、且版本与保存收据一致；其他设备修改或服务器触发后不能覆盖。只恢复几何，不能借撤销改变警报状态。明确失败时刷新记录与预览后重新确认；结果不确定时核对原操作 ID，避免重复平移。关闭或离开只取消未提交预览，已提交操作仍归原服务。

## 数据与效率

- 回调页与表格共用一个全量价格警报读取流，前台每 10 秒更新；手动刷新同时更新信号和警报。打开 K 线、离开行情或退后台暂停，不按行/周期增加请求。
- 复用 K 线的按警报 ID 串行保存队列和持久操作记录。保存前记录完整请求；进程重启恢复相同操作 ID 与正文。并发版本不匹配不自动换版本覆盖。
- 保存收据立即更新共享快照，并阻止在途旧 GET 回退几何；后续有效删除仍能移除记录。旧读取任务取消后的清理不能清除新任务或引发重复请求。
- 预览只读一条当前记录和一根 K 线；确认再读一根。验证响应品种/周期、未收盘标记、服务器时间与新鲜度；计算使用检查溢出的整数。请求可取消、有超时、并发有界，不在 UI 线程联网或等待线程退出。
- 品种使用惰性列表稳定键，警报分组随有效数据或时间边界缓存；静止无帧循环。周期不足或错误有明确文字，加载与失败不冒充无警报。
- 图表显式定位支持延期后整体位于未来的线段，时间视口与价格范围一起覆盖选中线段，不修改几何来实现定位。
