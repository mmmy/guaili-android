# 手机价格线警报实现与验证

版本：Guaili Android 0.3.0（versionCode 3）。验证日期：2026-10-06。此次扩展现有 Kotlin / Compose 手机K线界面，沿用 `GuailiTheme` 深色主题、Material 3 控件与原有图表；后端检测及桌面端已在各自工程实现。

## 使用

1. 打开K线页，选择「水平线」或「趋势线」，在图表依次点选起点和终点。第二次点选后打开警报设置；「取消绘图」可结束未完成的绘图。
2. 「条件」设置穿过、上穿或下穿，启用监测、到期时间、精确端点价格和设备本地时间、延伸方向、文字、颜色及线宽。「消息」编辑 TV 品种代码与 JSON 模板；「通知」编辑 Webhook URL。可保存为下次绘图的默认预设。
3. 点选已保存线段，显示端点手柄与底部操作栏。拖动线身移动整条线，拖动手柄修改对应端点；水平线端点保持同价。拖动时显示本地预览与原位置，松手后提交一次坐标修改，服务器确认后才显示保存成功。
4. 操作栏支持编辑、暂停 / 重新启用、触发记录、撤销最近一次已确认移动、删除和取消选择。「警报」列表也可选中已有绘图；触发记录每页读取 200 条，可查看更早记录、实际 JSON 正文和投递状态。

线段绑定创建时的品种与周期，切换图表周期不会修改绑定。价格按服务返回的真实最小价位对齐；精度不可用时可保存暂停线段。拖动冻结当次图表映射，避免实时行情或缩放改变手下的坐标。图表原有平移、双指缩放和光标操作保留；取消绘图及双指缩放不创建警报。

仅一次警报在触发后停止监测。移动活跃或已触发线段按服务器契约重新布防，手动暂停和已过期线段保留对应状态。编辑器关闭「启用监测」时始终显式保存 `status:disabled`，清除过期时间或改为未来时间也保持暂停；需打开开关才能启用。清空到期字段提交 `expiresAt:null`。

「警报 → 旧版固定价位」继续使用 `/api/alerts`，可修改价格、方向、URL、模板，暂停、重新启用或删除。旧版没有 v2 绘图手柄或 v2 触发记录；其到期时间只展示。v2 删除保留服务器历史事件，旧版删除行为仍由原接口处理。

## 保存与接口

v2 使用 `/api/price-alerts`，契约来源为 `F:\test\crypto-candlestick\docs\price-alerts-v2.md`。服务器负责穿越判断、一次触发、布防代次、事件持久化与 Webhook 投递；手机关闭后仍由服务器监测。

- 写请求携带不可变的 `mutationId`，修改 / 删除携带 `expectedRevision`，完整请求在网络写入前持久保存。同一警报最多一个写请求在途，连续移动只保留最新待提交坐标，使用上一请求确认的版本继续提交。
- 超时或响应无法确认时显示「保存结果待确认」，按原 `mutationId` 查询结果；确认未提交才重放原请求。版本冲突读取最新配置，等待用户明确重试或放弃。取消重试后，迟到的读取结果不能再提交修改；已知拒绝在重启后仍保持失败，不自动覆盖服务器配置。
- 默认 URL 与消息沿用现有 TV 模板。`price`、`period` 保持字符串，`noConfirm` 保持布尔值，例如 `"price":"{{close}}"`、`"period":"{{interval}}"`、`"noConfirm":false`。BUY / SELL、名称和描述由模板固定内容决定；v2 `{{ticker}}` 使用 TV 品种代码。

## 复现

在工程根目录使用 JDK 17 或以上、Android SDK 36：

```powershell
.\gradlew.bat :app:testDebugUnitTest :feature-xbot:testDebugUnitTest :app:lintDebug :feature-xbot:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest :app:assembleRelease
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
```

下面保存字号设置，分别冷启动运行两套价格警报测试，再恢复字号。`expectedFontScale` 会断言设备资源配置；恢复后重新打开应用即可：

```powershell
$priceAlertFontScale = (adb -s emulator-5554 shell settings get system font_scale).Trim()
try {
    foreach ($priceAlertScale in @("1.0", "1.3")) {
        adb -s emulator-5554 shell settings put system font_scale $priceAlertScale
        adb -s emulator-5554 shell am force-stop com.gouge.guaili
        adb -s emulator-5554 shell am force-stop com.gouge.guaili.test
        adb -s emulator-5554 shell am instrument -w -e expectedFontScale $priceAlertScale -e class "com.gouge.guaili.ui.PriceAlertInteractionTest,com.gouge.guaili.ui.PriceAlertExpiryIntentTest" com.gouge.guaili.test/androidx.test.runner.AndroidJUnitRunner
    }
} finally {
    if ($priceAlertFontScale -eq "null") {
        adb -s emulator-5554 shell settings delete system font_scale
    } else {
        adb -s emulator-5554 shell settings put system font_scale $priceAlertFontScale
    }
    adb -s emulator-5554 shell am force-stop com.gouge.guaili
}
```

单元结果为 `app/build/test-results/testDebugUnitTest/`、`feature-xbot/build/test-results/testDebugUnitTest/`，Lint 为各模块 `build/reports/lint-results-debug.*`。交互测试 PNG 和实际字号记录写到设备 `Android/data/com.gouge.guaili/files/price-alert-*.png`、`price-alert-*.metrics.txt`；每次运行会覆盖同名截图。
