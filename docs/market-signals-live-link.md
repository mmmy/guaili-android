# 表格与 V2 实时联动

2026-10-07。参考桌面端 A 的双向定位与 B/C 的窄宽布局，Android 使用实时选择，不保存固定证据。

## 操作

- 表格品种标题显示共振、近均线或分歧摘要，级数沿用 V2 选优规则。空间不足时显示 N 个信号，点击在信号栏选择；未监控、服务器未计算、预热、过期和无可见信号分别显示。
- 独立 V2 卡片主体继续打开最大参与周期的动态 K 线，右侧网格按钮定位表格。嵌入信号栏的主体选择并定位结构，右侧图表按钮打开 K 线。原实时详情保留，级数或长按可展开，不引入固定证据页。
- 定位保留表格布局与周期筛选。浅蓝边框表示当前所选有效结构的参与周期，分歧标记短+/短−、长+/长−。数值底色、ATR 过滤及前根趋势语义保留，格子继续打开指标详情。
- 选择后显示查看信号、K线、返回定位前、清除操作。被隐藏的成员可临时展开；品种或周期不在查询配置时临时加入当前行情页查询，缺失数据保持空值与原质量状态。
- 格子详情的“查看该周期的实时信号”打开品种与周期范围列表；“全部信号”恢复全列表。信号筛选不删掉表格其他品种。
- 手机按需在下方展开信号栏，选中结构后收起，让出表格空间。内容有效宽度达到 900dp、有效高度至少 400dp 时可并排：左侧信号栏，右侧表格，分别滚动；宽度按字体缩放折算，大字体或分屏自动回退。宽屏收起偏好持久保存。
- 返回按钮与系统返回恢复来源视图、布局、周期分组、选择、临时范围、品种范围和滚动锚点，最近八步有界保存。旋转和导航切换保留会话；切换服务器清除旧来源选择。

## 实时规则与资源

同一信号 ID 的参与周期可变化，选中范围和级数使用最新有效 V2 展示项。过期、关闭、失效或被筛选隐藏时清除参与边框并说明原因，K线入口禁用；不保留旧行情证据，不把暂不可判断称为解除。

信号与表格独立取数，表格可采用不同计算参数或收盘 K；参与边框不是表格数值同样满足服务端规则的保证。选择栏分别显示采样与表格更新时间、均线参数及前根趋势语义。自动刷新更新参与标记，不反复滚动追赶；滚动只响应明确定位与临时展开。

表格可见时启用同一个 V2 前台轮询，复用共享完整快照、刷新锁与一秒内复用机制，刷新不依赖小组件。每数据源最多一个在途请求，无逐行取数。V2 刷新成功同步小组件；表格失败不阻塞 V2。临时表格查询不覆盖小组件共享表格缓存，不持久修改品种、周期或计算设置。
