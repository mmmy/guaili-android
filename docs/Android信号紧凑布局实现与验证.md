# Android 信号紧凑布局

2026-10-12，用户确认“一行优先”原型并授权实现。该记录补充此前的界面层次同步，不改变主矩阵、回调观察或后端信号规则。

## 已实现的规则

- 应用 V2 独立页、侧栏及 V2／原有信号小组件：品种、周期、简短结构／阶段及级数尽量横向放在一行。空间不足时普通信号转为两行；分歧固定两段周期、最多两行。
- 周期保持 16sp 加粗，使用原来的正向、负向、近均线和分歧颜色；品种 12sp、辅助文字 11sp 常规字重。完整结构、EMA、阶段和级数留在应用详情；无障碍描述也保留完整字段。
- 内距纵向 2dp、横向 8dp、信号间距 2dp。小于 220dp 且字体放大超过 120% 的小组件将横向内距减到 2dp。应用整条摘要保持至少 48dp 触摸高度。
- 采用实际字体测量并缓存布局判断。周期优先完整；极窄分歧的次级品种可能省略，点击仍传递完整原品种与周期。
- 普通变化记录在说明中标记“原”，分歧变化记录保留两个“原”前缀；不能把已离开的范围当成当前活跃结构。
- 级数按钮在应用普通行右侧展开／收起详情，分歧通过品种入口和长按展开。周期和其余行区域保留 K 线／矩阵定位；过滤、状态、导航、选择清除、滚动恢复、缓存和刷新调度保持。

长期约定已同步到 [PRODUCT.md](../PRODUCT.md)、[DESIGN.md](../DESIGN.md)、[AGENTS.md](../AGENTS.md)、[V2 局部规范](../.impeccable/surfaces/market-signals.md) 与[小组件局部规范](../.impeccable/surfaces/guaili-widget.md)。

## 验证范围

Debug／Release 构建和 Lint 通过；应用单元测试 275 项通过，0 失败、0 错误。当前 Lint 0 错误、45 警告。

原生尺寸用例覆盖 180／250／320dp 小组件及 100%／150% 字体，每种包含普通、分歧、普通变化和分歧变化记录。断言范围单行、完整无省略、实际绘制为粗体且字号大于品种，摘要高度不超过两行的上限。320dp 普通样本含间隙实测约 27dp，窄屏样本约 44dp，分歧约 49dp；图来自 Android RemoteViews 实际渲染。

14 项不同仪器用例分轮通过。应用最终 9 项回归全部通过，覆盖筛选、展开与收起、长按、K 线原周期、视图保存、缓存／停止隐藏页轮询、侧栏联动及清除、仅 V2 格、刷新设置；另有 5 项组件验证覆盖标题／信号尺寸、真实桌面 V2 状态导航、原有信号组件和矩阵滚动。150% 字体／系统深色 3 项通过，最终应用排布在 150% 字体下再确认 1 项；宽屏 2 项通过。

手机环境为 API 36.1 模拟器，1080×2400、420dpi。宽屏检查使用同一模拟器扩展到 1600×1000、160dpi，不代替独立平板或真机验证。测试前备份为 `build/device-backups/20261012T134504694991Z`；测试恢复设置、缓存和组件配置，字体、尺寸、密度及系统主题恢复。为本轮 QA 添加了一个空提醒模式测试组件，未清除或卸载应用。

真实截图连接既有服务器；部分预热、动态 K 缺失、过期等提示如实保留。出现过一次远程请求失败，后续恢复；没有修改服务器。布局不新增轮询或独立请求，未进行真机帧率／输入延迟性能测量。
