# 桌面小组件局部规范

Mode: Operate. 继承 ../../PRODUCT.md 与 ../../DESIGN.md。

2026-10-16 新增 `WidgetMode.PullbackObservation`，仍由 `GuailiWidget` 配置和宿主承载；其局部规范见 [回调观察小组件](pullback-widget.md)。下文关于 Signals / V2 摘要、标题栏五项和结构颜色的约定不覆盖该模式。回调模式采用一行 48dp 顶栏、无底栏、目标 32/28sp 与多上空下的独立层次；它与 V2 共享服务器完整信号源，手动刷新只扩展到同源信号组件，不触发矩阵或决策提醒的独立读取。

仅订阅当前组件模式所需快照，按实际受影响的组件 ID 更新。前台已有信号直接交付缓存，不为重绘再发相同请求；同状态与同过期边界不重复写调度。局部修改与全量快照区分处理，晚到旧观测不能覆盖新结果，保留账户与服务隔离。

2026-10-16：矩阵成功刷新仅通知 Signals / Matrix / SingleSymbol，V2 和决策提醒保持各自来源。TV 快照编码和 RemoteViews 构建在后台，突发变化合并发布；广播与 worker 等待必要发布完成。后台观察值携带 scope 与 generation，编码、缓冲、重登和跨账户切换后仍校验来源，构建旧结果不得覆盖较新的组件设置。

2026-10-16 大字体验证补充：Signals/V2 的窄组件外层与信号行共用真实横向内距预算；宽度小于 220dp 且字体超过 120% 时，外层和行内横向内距均为 2dp，其余尺寸维持原值。标题栏始终保留计数、刷新状态、数据状态、编辑和刷新五项；有效文字宽不足时只缩短计数/刷新标签与间距，完整标题、状态及导航保留在无障碍描述，不缩小周期字号，不截断周期范围，不覆盖矩阵内距。

矩阵与分组组件以数值为重点，保留周期、数值字号和密度算法；品种分组标题与编辑、刷新弱化。V2 组件共用应用信号语义：彩色周期加粗，品种、结构和状态次级。

2026-10-12 已确认“一行优先”原型：默认单条摘要尽量一行、最多两行；纵向内距与信号间隙各 2dp，横向内距 8dp。按 Android 实际字体测量组合品种、周期和简短结构／阶段／级数，空间不足转两行。结构、EMA、阶段、级数不各占一行；分歧两段周期完整，极窄或大字体时次级品种可省略，完整信息保留在无障碍描述和应用详情入口。不能裁切周期或缩小全部文字，也不能删掉滚动功能。周期点击仍打开原品种／锚点 K 线；标题进入应用、编辑／刷新／状态导航保持。

保留所有点击导航、编辑、刷新、状态详情及无数据／过期提醒；保留日夜调色板和 Glance 响应式尺寸、列表节点限制。检查 180、250、320dp 组件宽度、字体缩放与深浅主题。禁止为层次调整增加后台轮询或持续动画。
