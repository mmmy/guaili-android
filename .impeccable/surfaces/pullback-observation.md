## 观察重点与布局

2026-10-14 用户纠正：移动端主级别、推荐小级别、右侧警报必须列对齐，不能接在每行不同宽度的文字后面。全页共用按字体和完整周期标签测量并缓存的列宽；候选/等待、短长标签、无目标 `—` 均保留列位置。小级别左对齐，独立点击区域至少 48dp。窄屏大字体保留原警报下移策略，各行数字列仍对齐；筛选和正常刷新不重新改变列宽。

2026-10-14 用户确认：正常无合格目标时只保留 `—`，不显示“同向级数不足”等说明。只有异常原因可在无目标行显示；窄屏纵向布局与常规横向布局一致，原警报内容和触摸区域保留。

入口为「行情 → 回调观察」，与表格、V2 并列。每品种多头在上、空头在下，目标级别直接表达方向与候选重要性。2026-10-14 用户要求移除主行上方重复的“多头／空头”文字，节省纵向空间；候选筛选只剩一行时仍有方向色及无障碍描述，依据标题与警报意图保留方向。品种用于定位；乖离、强度、阶段、参数摘要和控件保持辅助层。此层次与多绿空红只适用于回调页，不改矩阵、V2、K 线和小组件已有语义。

候选目标为 Material 3 headlineLarge（32sp / Bold），等待目标为 headlineMedium（28sp / Medium）。多头映射 secondary（当前 #A7F3D0），空头映射 error（当前 #FFB4AB）；候选直接使用方向色，等待从 onSurfaceVariant 向方向色混合 55%。候选背景 surfaceVariant 为中性 #202832，等待背景透明；选中以 primary 的 1dp 边框单独表达。品种 labelMedium 与乖离／说明 bodySmall 为 12sp，采样时间 labelSmall 为 11sp；辅助信息用 onSurfaceVariant，错误与不可用原因保持 error 可读。

应用在系统日夜模式下均沿用独立深色 GuailiTheme。目标行圆角 12dp、最小高度 64dp、横向内距 12dp、纵向内距 8dp；文字放大可增高。2026-10-12 用户确认工具栏只保留一行：级数参数入口、候选、声音、刷新，固定 56dp 高，控件至少 48dp、间距 8dp。候选／声音为图标＋短标签的 IconToggleButton，可直接切换；开启时使用 primary 16% 淡色底层／primary 原色文字，以及勾选／发声图标。保留完整无障碍名称和开关状态。移除重复观察标题及常驻规则摘要，完整参数在级数入口查看。窄屏、大字体也不换行；宽度／fontScale 小于 220dp 时参数入口省略 Tune 图标，级数与下拉标记始终可见。宽屏沿用导航侧栏，观察内容居中且最大 760dp。按品种稳定键复用 LazyColumn；底部面板可滚动，参数避让输入法。

## 参数、判定与质量

2026-10-14 用户确认：刚上线品种历史不足是正常情况。`warming_up` 且 `reasonCode` 为 `insufficient_history` 或 `indicator_warming_up` 时静默，不显示部分不可用、不计入待确认。保留周期占位、连续性阻断和未知证据的提醒身份；真实缺口、过期、恢复、无效值或等待行情等异常仍提示。混合状态的异常数量只计异常周期，不包含正常预热。

默认 N=5、T=10、K=2、最小目标级别 1 分钟、R=3。N 含目标；T 为整数 value 阈值；K 只计前 N−1 个背景。保存前校验 N 为 2–64、T 为 1–1000、K 为 1–N−1、R 为 0–1000；最小级别支持正分钟数字或 S / D / W，并按实际时长比较。最小级别与 R 位于「高级参数」，取消不保存，错误留在面板。

完整 `/api/signals` 证据按实际时长从大到小形成轴，缺失、过滤、重复别名、过期及无效证据占位并阻断连续性，不删掉后拼接。每个最大同向段从大级别起点观察固定的第 N 级，前 N−1 级按原始 guaili 正负同向，不把窗口滑向更小级别；每方向取最大的合格段。

背景全部 |value| < T 为弱势，至少 K 个背景 |value| ≥ T 为强势，其余普通；目标不计入强度。目标原始 guaili == 0 为触及均线，弱势／强势高亮、普通不高亮。原始非零但整数 value 为 0 仅是接近均线，不高亮。强势小幅反向要求整数 value 非零且 |原始 guaili| × 10 ≤ R；同向等待及反向超限不高亮。

只消费完整快照及 ready、未闭合、有限值且与原始 guaili 一致的证据；保留后端 qualityConfig、服务器时间和设备单调时钟的有效期判断。子集、过期、异常时基、缺元信息或非 live 状态不推断候选。有效零与缺失 `—` 分开，未知不能伪装成无候选。

2026-10-14 用户确认：回调只按 guaili 指标有效性判定，不受 V2 信号 `minHistoryBars`（默认 60 根）限制。外层周期仅因信号历史门槛为 `warming_up / insufficient_history` 时，优先使用同周期、同市场时间的 `guailiEvidence`；指标自身未预热、过滤、缺口、过期或无效仍阻断连续性。旧后端无新字段时保留外层判定。V2、原信号规则、小组件信号和提醒规则保持不变，不新增轮询；依据展示使用实际参与回调的固定证据。

2026-10-14 用户纠正：手机缓存有效期必须覆盖已配置刷新周期，取 max(后端 maxResultAgeMs, 手机刷新间隔 + 12 秒请求超时)。收到响应时，以 response.serverTime 校验 evaluatedAt、品种 sampledAt 与周期 marketEventTime，保留后端有效期和 2 秒未来时间容差；同一有效缓存不会在正常刷新间隔中途丢失候选。手机刷新超时、后端采样停滞、采样时间异常使用不同的短提示，保持现有错误文字层次。修改自动刷新间隔即时重建投影与到期边界；失败或挂起超过手机缓存有效期仍撤下候选，未知不重新触发声音。

## 推荐入场小级别

2026-10-13 同步桌面确认的规则：入场倍数默认 20，参数面板常规区可编辑并校验 2–1000，取消不保存，旧偏好自动取得 20。从全局固定表取与回调周期 ÷ 倍数的实际时长最接近、且严格小于回调周期的级别；等距取更小周期，不受单品种是否配置或该小周期证据是否可用影响。

全局表在 `data/MarketPeriods.kt`：10S、15S、30S、45S；1、2、3、5、8、10、15、20、30、45 分钟；60、90、120、180、240、360、480、720 分钟；D、2D、3D、4D、W、10D。整小时用 H 显示，例如 2D ÷ 20 → 2H；最小周期无更小选项时显示 — 并保留明确的无障碍描述。不是入场确认或当前小级别行情可用性的断言。

推荐数值采用中性 titleMedium / 16sp，紧邻回调级别且与其垂直居中对齐；不显示“入场参考”文字标签，回调方向色和 32/28sp 层次保留。独立入口至少 48×48dp、与回调级别间距 8dp；移动端单击打开同品种、当前推荐周期的 K 线，使用原导航链路保持返回位置，不借用固定依据的大周期、不触发整行依据。无更小周期时不提供小周期入口。

推荐仅在投影重建时查静态预计算时长表，结果随候选缓存，UI 不随重组查表或新增请求；标签按推荐周期记忆。参数变更、选择取消、候选过滤、声音与生命周期沿用既有规则。

## 价格警报同步与延期（2026-10-14）

2026-10-15 用户补充：警报有就显示、没有就空白，同时保留启用中与已触发记录。已触发显示“已触发”，查看、刷新、重进及原有效期经过不清除；移动线段或重新设置后跟随服务端新状态更新。无可显示警报时不显示空状态、加载或重复待更新占位；请求异常沿用页级统一提示，保留上次记录，已触发文字不被“待更新”替换。主级别、小级别和警报的共享列位置保持。

用户已确认原型并要求全部实现。复用行情服务的价格警报读取流，前台表格和回调页共用一个每 10 秒的全量请求，不按品种或单元格重复请求；离开行情、打开 K 线或退后台暂停。保存收据及时更新共享快照并刷新，避免在途旧响应把延期后的几何恢复；加载/错误不冒充无警报，失败保留上次记录并显示待更新。

主信号右侧替换原乖离说明，聚合意图、14sp 周期、精确价格、11sp 状态；多绿空红继续只作用于回调级别，警报摘要保持中性，异常暖色可读。普通摘要两行优先，状态可随宽度换行；有效宽度低于 280dp 时在目标行内纵向排列级别组与警报组，允许行高随字体增长，不压缩 32/28sp 主级别、16sp 小级别与 48dp 触摸区。乖离及阶段仍在固定依据中。

做多/平多归 Long，做空/平空归 Short，旧或未知意图归未分类。每方向一条稳定主警报，其他 +N 在原生底部面板展示，可设为主；选择按服务地址+品种+方向保存。失效选择回退稳定 ID，不覆盖另一服务同 ID 的选择。常驻显示启用且有效的警报及已触发警报；触发不改变原主警报选择，暂停与未触发的过期记录仅保留原 K 线列表/历史。已触发记录不提供延期，不在本地重置或重新布防。摘要单击打开原 symbol/interval/alert ID 的 K 线，原级别仍打开依据，小级别独立打开推荐周期；返回保持滚动，关闭面板和取消选择后刷新不恢复。

启用、未到有效期且不延伸的有限线段结束后，主行与展开面板提供“延期”。全局根数 extensionBars 默认 20，范围 1–1000，参数取消不保存，旧文件默认 20；独立于回调规则，不重置候选或声音基线。手机点击延期先读最新记录和一根未收盘 K 线，预览原/新起止时间，再确认；确认时重新取最新 K 线。新终点=最新开盘时间+根数×警报绑定周期，起点等量后移；保留原时长、端点价格、延伸方式、意图、有效期、通知与历史。未来起点明确提示等待，过期警报和无限延伸线段无延期入口。

延期和图表操作共用按 ID 串行的持久操作队列，重复点击不再次提交；收据不确定时核对同一操作 ID。明确失败先刷新记录和预览再确认，不能自动换新版本覆盖。成功后页内提示 10 秒可撤销，要求 ID、版本、启用与有效期仍一致；其他设备编辑或触发后禁止覆盖。撤销只恢复几何，不自动改警报状态。关闭/离开取消只读预览，已提交操作不取消、不改服务归属；重启恢复操作收据。图表定位兼容移到未来的警报线段，不能通过改变几何实现定位。

## 筛选、依据与提醒

「只显示回调候选」和「声音提醒」分别保存且默认关闭，回调参数与原表格／V2 筛选互不覆盖，旧偏好取得默认值。候选筛选只显示高亮方向，无候选品种隐藏；筛选不改变声音判定。

依据固定打开时的目标、背景、规则、均线参数和采样时间，刷新不替换这份证据；当前质量失效时提示不可确认。关闭按钮、系统返回和遮罩取消选择；刷新不得恢复已取消状态。打开参数或切换候选筛选也清除选择。K 线传入原 symbol 与 interval，返回保留视图及列表位置。

提醒身份为品种＋多空方向＋实际周期时长，一次更新有多个新候选只发一个短通知音，持续候选不重复提醒。有效证据确认消失后再出现可重响；未知、缺失、断网与过期不能证明消失。启动、重新进入、开启声音、改规则或换服务器静默建立基线。只在前台回调观察页发送 SharedFlow 事件，ToneGenerator 使用通知音量、按生命周期复用并释放，不新增后台服务。

复用 ServerSignalsViewModel、完整快照缓存、现有刷新协调器和可取消请求，不新增行情轮询。快照、规则或质量边界变化时重建投影，复用有效期间的排序；离开行情、打开 K 线或退后台遵守现有前台暂停边界。刷新保持观察位置。
